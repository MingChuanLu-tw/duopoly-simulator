# Week 5 雙頭寡占競爭模擬器

雙頭寡占競爭模擬器 Duopoly Competition Simulator：單一 `index.html`，可在瀏覽器直接操作，不需安裝。

## 這是什麼

用同一組需求與成本參數，比較雙頭寡占（duopoly）三種經典競爭模型的均衡結果：

| 模型 | 競爭變數 | 重點 |
| --- | --- | --- |
| Cournot | 數量 | 反應函數、納許均衡 |
| Bertrand | 價格 | 同質產品與差異化產品兩種情況 |
| Stackelberg | 數量（先後行動） | 領導者優勢 |

另外附有完全競爭與獨占作為對照基準。

## 主要功能

- 拖曳滑桿調整需求截距、需求斜率、兩家廠商的邊際成本與產品差異化程度，結果即時更新
- 市場圖、反應函數圖、等利潤曲線
- 均衡價格、產量、利潤，以及消費者剩餘（CS）、社會福利（SW）、無謂損失（DWL）
- Lerner 指數、HHI 集中度
- 三種模型並排比較表，以及 5 組預設情境
- 三段動畫教學：Cournot 輪流調整收斂、Bertrand 不斷削價、Stackelberg 領導者尋找最佳產量
- 中英對照介面，公式以 KaTeX 排版，圖表使用 Plotly；函式庫載入失敗時有備援顯示
- 手機寬度可用

## 模型設定

線性需求：`P_i = a − b·q_i − γ·q_j`，產品差異化程度 θ = γ / b。
成本為固定邊際成本 `c_i`，無固定成本。

## 如何使用

直接開啟上面的網址即可。若要在本機執行，下載 `index.html` 用瀏覽器開啟。

網址後面加上 `?test=1` 可執行自我測試，共 58 項檢查，涵蓋規格書數值案例、極端值與 Stackelberg 封閉解對照。

## 製作方式

使用 AI 輔助的 Vibe Coding 流程：先與 AI 討論並寫出規格書，再分階段產生程式（V1 計算核心與測試 → V2 介面 → V3 補強功能 → V4 動畫教學），每一階段都經過檢查與修正。詳見作業附上的「規格書」與「對話過程」。
